# Prompt Structure Guidelines

With prompts we are building, providing structure and guidelines.

## Order of the Structure

### [Context] (Optional)
Provides the background or context for the task.

**Examples:**
- As a developer, write a legal email.
- As a project manager, create a status report.

### [Task] (Mandatory)
Defines the action to perform.

**Requirements:**
- Must start with a verb.
- Clearly describe the expected outcome.

**Examples:**
- Write code.
- Create a report.
- Generate an email.

### [Examples] (Optional)
Provides examples to improve the quality of the result and help achieve the desired outcome.

### [Persona] (Optional)
Specifies the role from which the response should be generated.

**Examples:**
- Developer
- Tester
- Business Analyst
- Product Manager

### [Format] (Optional)
Defines the expected output format.

**Examples:**
- Email
- Chart
- Table
- Report
- Markdown

### [Tone] (Optional)
Specifies the writing style or communication tone.

**Examples:**
- Casual
- Formal
- Professional
- Friendly

## Recommended Prompt Structure for Developers

1. **Context**
2. **Task**
3. **Input** (data)
4. **Examples** to obtain better results
5. **Testing Examples**
