# GitHub Copilot Core Slash Commands

> Core slash commands commonly available in GitHub Copilot Chat (VS Code and related IDE experiences). Availability may vary by IDE, extension version, and context.

| Command | Purpose | Typical Use |
|----------|----------|-------------|
| `/explain` | Explain selected code in natural language | Understand unfamiliar code |
| `/fix` | Identify issues and suggest fixes | Debug errors and code problems |
| `/test` or `/tests` | Generate unit tests | Create test coverage for functions/classes |
| `/doc` | Generate documentation/comments | Create JSDoc, XML comments, docstrings |
| `/refactor` | Suggest code refactoring | Improve maintainability and design |
| `/optimize` | Suggest performance improvements | Improve efficiency and reduce complexity |
| `/new` | Generate new code from a description | Scaffold components, classes, functions |
| `/help` | Display available commands and usage | Discover Copilot capabilities |
| `/clear` | Clear the current conversation | Reset chat context |
| `/delete` | Delete a conversation | Remove chat history |
| `/rename` | Rename a conversation | Organize chat sessions |

## Notes

- Type `/` in Copilot Chat to see commands available in your current environment.
- Command availability varies between VS Code, Visual Studio, JetBrains IDEs, GitHub.com, and the Copilot App.
- Some environments include additional commands beyond the core set listed above.
